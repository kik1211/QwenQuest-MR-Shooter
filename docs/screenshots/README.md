# docs/screenshots

This directory holds the images referenced in the root `README.md`.

## Required Files

| File | Where it appears | How to create |
|---|---|---|
| `hero.png` | README hero shot | Quest screen recording via **Quest Casting** app, save a frame |
| `architecture.png` | System architecture section | Export from draw.io, Excalidraw, or PowerPoint |

## Optional Files

| File | Where it appears | How to create |
|---|---|---|
| `gameplay.gif` | README overview GIF | Convert a Quest screen recording MP4 via ScreenToGif or ezgif.com (keep under 10 MB) |
| `unity-editor.png` | Setup guide | Screenshot of Unity Editor with main scene open |
| `terminal.png` | PC Hub setup | Screenshot of `tactical_hub.py` running in terminal |
| `dashboard.png` | Phone dashboard section | Screenshot of `index.html` open in a phone browser |

## Guidelines

- Keep image dimensions ≤ 1920 × 1080 for fast GitHub loading.
- Use `.png` for static screenshots, `.gif` for short clips (< 30 s).
- Do **not** commit images larger than 10 MB to this directory — use a CDN or GitHub releases instead.
